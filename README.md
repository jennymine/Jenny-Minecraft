# Jenny Mod Minecraft

**Jenny Mod Minecraft v2.1.0** adds companion NPCs with custom outfits and animations across Java Forge (`1.20.1`, `1.21.1`, `1.12.2`) and Bedrock `.mcpack` worlds.

### Java Edition (Forge)
- Drop the v2.1.0 `.jar` into your Forge `mods/` directory.
- Adjust entity spawn rates and outfit presets inside `configs/spawn_rules.toml`.

<img width="1280" height="720" alt="images3" src="https://github.com/user-attachments/assets/1362a381-840b-4c62-aee7-57a4d6daa632" />

### Bedrock / Pocket Edition
- Import both the Resource Pack and Behavior Pack `.mcpack` archives.
- Enable experimental creator toggles in world settings before loading.

## Compatibility Check
If entity limbs fail to render alongside Optifine or shader packs, disable entity-culling flags in your video settings and verify your Forge build matches `1.20.1` or `1.21.1`.
